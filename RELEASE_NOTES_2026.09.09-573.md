# CupNavi v573 – Youth kit search + informational clashes

- Tröj setup searches more intelligently for local youth teams by using tournament location/country, age class and squad suffixes such as P2014, F2013, U13, Svart/Blå.
- Optional per-team search hint can supply town, club URL or district association.
- Home and away evidence are tracked separately; partial grounded results can be reviewed without inventing an unverified second kit.
- Unverified sides keep the team's existing editable kit values until the organiser changes them.
- Colour clashes are advisory information only and never block schedule/publication or become a required action.
