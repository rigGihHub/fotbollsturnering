# v392 – Interactive Setup Wizard

New tournaments now open in a focused five-step wizard instead of the full settings page.

1. Arrangement type and result mode
2. Competition classes and planned teams
3. Pitches, verified addresses and available times
4. CupNavi recommended format
5. Readiness check and handoff to Teams

The full setup editor remains available later from Cup settings. The wizard only changes the first-run experience.
