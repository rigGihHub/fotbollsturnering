# CupNavi v.1.191 – Beautify audit

## P1 findings addressed
- Multiple visual vocabularies had accumulated across releases: different radii, shadows, muted colors, button weights and card treatments.
- Fixed logo used gradient/glass/pill styling and occupied too much mobile header space.
- Public desktop navigation used emoji icons while the rest of the product mixed icon styles.
- Mobile public navigation omitted Cupinfo, creating functional parity loss.
- Several empty states were passive messages instead of explaining what happens next.
- Dense data views lacked a single table rhythm and consistent sticky heading treatment.
- Keyboard focus and reduced-motion behavior were not defined as a product-wide system.

## P2 findings addressed
- Large-screen content width could feel either too wide or uneven between views.
- Streamlit forms and bordered containers retained prototype-like native variation.
- Public PWA and Streamlit view did not share a sufficiently explicit token vocabulary.

## Intentionally unchanged
- Business logic, setup structure, permissions and lifecycle rules.
- Advanced tournament options; complexity was presented more consistently rather than removed.
- Domain-specific table qualifier colors, because they communicate real competition state.
