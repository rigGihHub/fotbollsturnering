# CupNavi 2026.09.07-496-PUBLIC-UX-POLISH

Public UI polish based on live visual QA:

- Cupklockan gets a taller iframe and border-box sizing so the lower date/timezone row is not clipped.
- Tillgänglighet is visually quieter and pinned at the lower-left edge of the desktop sidebar.
- Primary public navigation labels are forced to one line, including narrow phone breakpoints.
- Målskyttar och kort now lives inside Filter & visning beside the weather choice; it remains enabled by default when event details are available.
- Hitta på cupområdet uses the same card geometry, hierarchy and visual language as Praktisk information.
- Dela is compressed into one compact popover with no deliberate internal scrolling: link, share channels, QR, PDF and Informationsskärm are visible together.

No tournament write, result, playoff, schedule or database safety semantics were intentionally changed.
