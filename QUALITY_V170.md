# QUALITY V170
Release: 2026.08.25-170-FORMAT-RECOMMENDER

- Explainable format recommender based on sport, team count, pitch capacity, match duration and compactness.
- Recommends group count/size, playoff size and estimated total matches.
- Capacity check warns before accepting unrealistic formats.
- Recommendation is advisory until user explicitly accepts it.
- Accepted recommendation can create empty groups in Admin; teams are never moved automatically.
- Admin can review the saved recommendation.
