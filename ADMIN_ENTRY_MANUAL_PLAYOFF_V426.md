# CupNavi v426 – Admin entry, manual playoff and single team-count choice

- Admin now opens on a clean two-choice screen: create a new cup or administer an existing cup. Existing-cup administration requires choosing the cup before admin navigation is shown.
- Tournament setup can run group play without result counting while still using a manually seeded playoff. The organiser selects 2/4/8 teams, creates the bracket and advances winners manually without entering scores.
- The public playoff view can show the manual bracket even though group result counting is disabled.
- Step 2 no longer forces the planned team count to be entered twice. The saved count is shown as text and only becomes editable when the organiser explicitly chooses “Ändra lagantal”.
