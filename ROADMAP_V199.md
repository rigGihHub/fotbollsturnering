# CupNavi – Roadmap after v1.199

## DO NOW
- Behavioral regression guards for navigation and other recently fixed failures.
- Extract the next safest public-view subdomain only when tests cover it.
- Strengthen critical journey E2E around create → schedule → publish → result.

## DO NEXT
- Incremental service-layer extraction for UI mutations.
- Production telemetry/error reporting.
- Visual regression coverage before deleting legacy CSS.
- Accessibility automation plus physical/manual verification.

## DO LATER
- Measured load testing and scale-triggered database/cache changes.
- Further PWA/API expansion where it reduces Streamlit limitations.

## DO NOT DO
- No big-bang rewrite.
- No speculative 100k-user infrastructure.
- No deletion of backup/history/security/admin controls for UX minimalism.
- No mass CSS deletion without visual regression evidence.
