# CupNavi v553 – Referee + Misc + Smart Selective Import

- Domare is now its own primary step 6 of 9, but remains optional and never blocks publication.
- Main flow: Cupinfo → Lag → Grupper → Regler → Planer & tider → Domare → Schema → Kontroll → Publicera.
- New Övrigt workspace sits outside the numbered flow for sponsors, offers, functionaries, analytics, tools, access codes and import.
- Image import now starts with a discovery pass. CupNavi only shows information categories actually detected in the image, confidence and concrete findings, then asks the organizer what to continue with.
- Nothing from the discovery pass is written automatically; the organizer must choose and review first.
