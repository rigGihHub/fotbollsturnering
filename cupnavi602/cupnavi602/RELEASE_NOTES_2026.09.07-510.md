# CupNavi v510 – Manual Imported Schedule Edit

- Befintliga scheman, inklusive foto/PDF-importerade scheman, kan redigeras manuellt utan omgenerering.
- Admin kan ändra datum, avspark, plan och domare för ospelade matcher.
- För gruppspelsmatcher kan hemma- och bortalag korrigeras inom samma grupp.
- Spelade matcher skyddas.
- En manuell ändring avpublicerar schemat och kräver ny kontroll före publicering.
- Övriga matcher lämnas orörda.
