# CupNavi v574 – Multi-strategy Youth Kit Search

Tröj setup får en bounded fallback-sökning för små och svårhittade ungdomslag.

- Försök 1: exakt lagnamn + cupens ort/land/åldersklass/sökledtråd.
- Försök 2: sannolikt klubbnamn utan vanliga P/F/U-, färg- och truppsuffix.
- Försök 3: lokal/visuell källjakt via klubbsite/webbshop, lagsidor, distriktsförbund/cupsidor och färska matchbilder.
- Stoppar direkt när ett faktiskt källbelagt hemma- eller bortaställ hittats; max tre sökförsök per lag.
- Visar vilken sökväg som lyckades eller vilka som provats.
- Enskild lag-sökning använder nu samma cupkontext och sökledtråd som massökning.
- Inget sparas utan uttryckligt Godkänn och spara.
- Färgkrockar förblir ren information och blockerar ingenting.
