# CupNavi v572 – Tröj setup / web scan

- Ny adminyta **Tröj setup** under Deltagare.
- CupNavi kan webbsöka lagens aktuella hemma- och bortaställ med OpenAI Responses API web search.
- Hela cupens lag kan scannas i en körning eller ett lag i taget.
- Förslag innehåller säkerhetsnivå, färger, mönster, preview och använda källor.
- Inga AI-förslag sparas automatiskt: arrangören måste granska och godkänna varje lag.
- Färg och mönster kan redigeras före godkännande och senare på Lag-sidan.
- Osäkra/okända lag får inget gissat förslag.
