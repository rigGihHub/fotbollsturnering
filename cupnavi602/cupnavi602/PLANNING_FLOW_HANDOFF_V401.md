# v401 – Planning flow handoff

CupNavi now keeps the first organiser journey consistent from setup through publication.

- The next-step engine no longer treats optional rosters or referees as mandatory blockers in the first planning journey.
- A completed, unpublished schedule now leads to **Kontroller** instead of skipping straight to result reporting.
- The main admin recommendation and Adminöversikt follow the same order: Lag → Grupper → Schema → Kontroll → Publicera.
- Kontroll is visually identified as step 4 of 5, matching the wording already used in Lag, Grupper and Schema.
- After publication, the recommendation moves into the live workflow (results, then competition state).
