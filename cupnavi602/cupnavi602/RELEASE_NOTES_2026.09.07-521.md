# CupNavi v521 – Public desktop match focus

- Publikvyn använder betydligt mer av tillgänglig desktopbredd.
- Cuphuvudet får större titel och tydligare datum/plats medan systemtext tonas ned.
- Turneringsvy/Admin-växeln görs mindre framträdande.
- Matchkorten prioriterar tid, lag, resultat och plan med större typografi och mer luft.
- Sekundär information, filter och statistik behåller lägre visuell vikt.
- Mobilens kompakta layout lämnas oförändrad.
