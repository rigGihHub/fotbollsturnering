# v507 – REVIEWED DOCUMENT SCHEDULE IMPORT

- Dokumentimportens hittade gruppspelsmatcher kan nu korrigeras direkt i previewn.
- Matchprogram skapas bara efter ett separat, uttryckligt godkännande.
- Importerade matcher får tid och plan och låses som ett befintligt schema.
- Ett redan existerande schema stoppar importen; ingen automatisk överskrivning sker.
- Okända lag, fel grupp, saknad plan eller ogiltig tid avbryter hela matchimporten atomiskt.
- Slutspelsförslaget är fortsatt preview-only tills källberoenden kan mappas säkert utan gissningar.
