# CupNavi v606 — Premium Sports Design System

## Design direction
Nordic Sports Control Room × Text-TV 330.

## Palette
- Base: #08131C / #061019
- Surface: #0D1D28 / #112633 / #173140
- Primary text: #EDF5F7
- Secondary text: #C1D1D7
- Muted: #8DA4AE
- Focus/navigation: #42C9D8
- Success: #5BD38A
- Warning: #E8BD5B
- Error: #EE777F
- Info: #76BDE8

## Changes
- Softer navy hierarchy for prolonged viewing instead of pure black/white contrast.
- Aqua is reserved for navigation/focus; semantic green/yellow/red retain meaning.
- Three-level surface system with restrained borders and almost no decorative glow.
- Marketing/public hero and admin use the same visual language.
- Compact control-room treatment for the nine-step cup journey.
- Subtle 150 ms interaction feedback with reduced-motion support.
- Text-TV sport data remains deliberately blacker and more utilitarian.
- Legacy light islands are suppressed, except the intentionally light calendar.

No tournament, scoring, scheduling, permissions or persisted-data logic changed.
