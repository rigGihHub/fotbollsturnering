# v1.253 – Sökning som faktiskt öppnar rätt objekt

## Förändring
Global Admin-sökning navigerar nu med objektets identitet, inte bara med sidnamnet.

- **Lag** → Lag-vyn med det sökta laget framlyft.
- **Spelare** → Trupper med spelarens lag automatiskt valt och spelaren markerad.
- **Domare** → Domare med den sökta domaren framlyft.
- **Matchnummer** → Resultat med den sökta matchen framlyft.

Sökfältet töms när Öppna används så att det blir tydligt att navigationen faktiskt har skett.
